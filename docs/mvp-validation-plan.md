# MVP 1.0 首轮用户验证计划

对象：5–10 名会自行拍摄短视频的小商家、电商卖家、服装/美妆/餐饮内容创作者或个人 IP。使用 `Tester 001` 等编号，不收集真实姓名。

每人从 `/test/start` 进入，完成参考视频、拍摄方案、逐镜拍摄、成片、反馈和价格测试。观察员在 `UserTestSession.observerNotes` 记录访谈原话。

建议观察阈值（样本很小，只用于决策，不作为统计显著性结论）：

- ≥60% 首次测试用户生成 FinalVideo；
- ≥50% 选择“直接发布”或“稍微改一下会发布”；
- ≥60% 选择“一定会”或“可能会”再次使用；
- 5–10 人中至少 2 人主动选择模拟付费套餐。

额外观察：漏斗流失阶段、阶段耗时、AI 建议重拍后用户重拍/强制采用的比例、Provider 失败率、每完成项目的 credits 与调用次数。不要将真实用户视频用于 Provider Benchmark；正式处理前必须有清晰的隐私告知和数据流说明。
